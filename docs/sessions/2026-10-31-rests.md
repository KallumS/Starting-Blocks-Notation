# 2026-10-31 - rests for a part as played

## Asked

From Middaw, which engraves its clips with this engraver: a rest inside a
phrase printed as a longer note. "Yes please" to fixing it here.

## Done

- `opts.rests` on `N.layout` (decision 0019): with it, a note is written to
  where its sound stops, rounded up to a sixteenth, and a rest only where a
  sixteenth or more is left. Without it, 0005 as before; the window does not
  pass it.
- Five checks in `test_notate.lua`; the first fails on the old engraver.

## How it was run

There was no Lua 5.4 in the session. The suites were run with Middaw's own
Lua 5.4 (`tools/lua.js` in that repo, held byte for byte to the real one):
`test_notate` 289, `test_engine` 485, `test_draw` 96, `test_midi` 81, all
passing, and `docs/BLOCKS.md` current. `test_ui`, `test_place` and
`test_plugin` need `os.execute`, which that Lua does not have, so they were
not run; nothing they drive passes the new option. Run `tools/test.sh`
before relying on it.
